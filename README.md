# David Schnitman — Portfolio

Personal portfolio site from [dschnitman-ideo/fuzzy-guide](https://github.com/dschnitman-ideo/fuzzy-guide). It is a Next.js app with selected projects (Wall Street Journal, Abbott Diabetes Care, Last Mile Money, generative art) and an about page.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

To use a specific host and port:

```bash
npx next dev --turbo -H 0.0.0.0 -p 43123
```

## Scripts

- `npm run dev` — development server with Turbopack
- `npm run build` — production build
- `npm start` — serve the production build
- `npm run lint` — ESLint
